Cuestiones teóricas de la práctica Respuestas a las Preguntas Planteadas

1. ¿El componente usa Sass por defecto?

Sí. En Ionic con Angular, la configuración del proyecto en angular.json establece que los generadores de páginas y componentes utilicen la extensión .scss ("styleext": "scss" y "inlineStyleLanguage": "scss"). Al crear el proyecto con la plantilla blank, el componente HomePage ya viene vinculado a home.page.scss.

2. ¿Aplico Sass pero se compila solo? ¿Por qué no hacemos npm run watch:sass?

Sí, se compila de forma 100% automática y en memoria. A diferencia de proyectos web planos (como m9-3-sass-fundamentals) donde se requiere un watcher manual de Node (sass --watch), al ejecutar ionic serve se delega en el builder moderno de Angular CLI (@angular/build:application con Vite/esbuild). Este pipeline integra el compilador de Sass de forma nativa, recompilando al instante y aplicando Hot Module Replacement (HMR) cada vez que guardas un cambio.
